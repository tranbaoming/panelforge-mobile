# PanelForge Mobile (panelforge-mobile)

PanelForge is a modern Flutter mobile application designed for comic reading and collaborative pre-release review workflows.

## Key Features
- **Comic Reader**: Webtoon vertical scroll, horizontal page flip mode, interactive scrub bar, and panel navigation.
- **Review Canvas & Hub**: Pinpoint annotation on comic panels, comment threads, dynamic watermarking, and security expiry controls.
- **QR Code Scanner**: Scan invite codes and review tokens directly from the camera or image gallery.
- **Rich Theming**: Dark/Light mode inspired by Webtoon & Figma styles with custom copper/gold accents.

## Tech Stack
- **Flutter SDK**: 3.x+
- **Routing**: `go_router`
- **State Management**: `flutter_riverpod`
- **QR Scanner**: `mobile_scanner`
- **Icons**: `lucide_icons`

## Getting Started

1. **Install dependencies:**
   ```bash
   flutter pub get
   ```

2. **Run app:**
   ```bash
   flutter run
   ```
